# Task-Specific Annotation Rubrics

## Status

Task-specific annotation rubrics define the operational meaning of the
criterion identifiers used by the scoring protocol.

Version 0.1 registers rubrics for all three pilot task types:

- `FALSE_PREMISE_CORRECTION`
- `EPISTEMIC_UNCERTAINTY`
- `BENIGN_REQUEST`

The rubrics define human judgments.

The scoring protocol determines how those judgments map to response-level
outcomes.
